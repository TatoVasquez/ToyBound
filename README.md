# ToyBound
Juego creado en Unity para un proyecto de universidad hecho en 5 semanas. 

Modelados y UI hechos por Gabriela Garcia. Animaciones y programación hecha por mi persona, Eduardo Vasquez.

El juego trata de un robot de juguete quien debe volver a casa.

Un juego del género "Plataformas". Son 3 Niveles donde en cada uno debe recoger 3 llaves para poder seguir al siguiente nivel.
